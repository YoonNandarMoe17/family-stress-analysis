ABOUT THE SYSTEM

Turning Family Data Into Meaningful Insights

The Family Stress Analysis system applies data mining and machine learning techniques to examine relationships between personal, family, employment, income, and work-family factors. The system combines descriptive mining for discovering patterns with predictive modelling for classifying stress categories.

DATA MINING METHODS

How the Data Is Analyzed

Multiple data mining techniques are used to examine the dataset from different perspectives.

📊

K-Means Clustering

Groups individuals with similar characteristics based on important numerical family and work-related factors.

DESCRIPTIVE MINING
🔗

Apriori Association

Identifies combinations of factors that frequently occur together with particular stress categories.

PATTERN DISCOVERY
🧩

Factor Association

Examines the strength of relationships between numerical and categorical factors and stress.

ASSOCIATION ANALYSIS
🤖

Random Forest

Uses an ensemble machine learning model to classify individuals into Low, Medium, or High stress categories.

PREDICTIVE MINING
📈

Model Evaluation

Evaluates prediction performance using accuracy, precision, recall, F1-score, AUC, and cross-validation.

EVALUATION
🔍

Pattern Interpretation

Presents important findings through an interactive dashboard so that the discovered patterns can be understood more clearly.

KEY DESCRIPTIVE FINDING

Work-Family Balance Shows the Strongest Association

Among the numerical factors analyzed, Work-Family Balance showed the strongest association with stress category, with an Epsilon-squared effect size of 0.3480. This indicates that work-family balance was the most strongly associated numerical factor in the factor association analysis.
